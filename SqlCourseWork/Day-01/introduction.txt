Rows + Columns = Table



Hierarchical Model
=========================
Data is organized in a tree-like structure.
It has a parent-child relationship.
One parent can have multiple children.
Each child usually has only one parent.


Relational Model
===================
Data is stored in tables.
Tables contain rows and columns.
Tables can be connected using keys such as Primary Key and Foreign Key.
SQL is used to create, store, retrieve, and manage data.

Object-Oriented Model
=======================
Data is stored as objects.
An object contains data + methods (behavior).
It follows OOP concepts such as class, object, inheritance, encapsulation, etc.
 Network Model
===================
Data is organized in a network/graph structure.
It supports many-to-many relationships.
A record can have multiple parent records.
It is more flexible than the hierarchical model.
Object-Relational Model
===================
It is a combination of Relational Model + Object-Oriented Model.
Data is mainly stored in tables.
It also supports object-oriented features such as objects, custom data types, and methods.
It provides the advantages of both relational and object-oriented models.
SQL Data Types 
=====================
numeric datatypes
=========================
INT → Stores normal whole numbers. Example: 10, 100
BIGINT → Stores very large whole numbers.
FLOAT → Stores approximate decimal numbers.
DOUBLE → Stores decimal numbers with higher precision than FLOAT.
DECIMAL → Stores exact decimal numbers, mainly used for money.
TINYINT → Stores very small whole numbers.
BOOLEAN → Stores TRUE or FALSE values.
strings:
===============
CHAR → Stores fixed-length characters or strings.
VARCHAR → Stores variable-length characters or strings.
TEXT → Stores large amounts of text.
ENUM → Stores one value from a predefined list of values.
data and time
=====================
DATE → Stores only the date. 
TIME → Stores only the time. 
DATETIME → Stores both date and time.
TIMESTAMP → Stores date and time, commonly used for recording when something was created or updated.
Constrains:
======================
PRIMARY KEY	:Uniquely identifies each row. Cannot contain NULL.
FOREIGN KEY	:Links one table to another table's primary/unique key.
NOT NULL	:Ensures a column must have a value.
UNIQUE	:Ensures all values in a column are different.
DEFAULT	:Automatically provides a value when no value is specified.
